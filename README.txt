DINO SIFIR 2–9 — PWA

Fail:
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png

Cara guna:
1. Upload semua fail/folder ini ke hosting HTTPS seperti GitHub Pages, Netlify atau Cloudflare Pages.
2. Buka URL laman tersebut pada telefon.
3. Android/Chrome: tekan butang 'PASANG APP DINO SIFIR' atau menu > Add to Home screen.
4. iPhone/Safari: Share > Add to Home Screen.
5. Selepas dipasang, app akan muncul sebagai ikon Dino Sifir dan dibuka dalam mod standalone.

Penting:
- Jangan host fail ini terus melalui Canva kerana fungsi JavaScript/PWA tidak stabil di dalam import Canva.
- URL Google Apps Script backend untuk rekod murid sudah dimasukkan dalam index.html.
